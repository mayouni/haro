~~~ The fixtures of the BLOCK kind (rung 5 of the code-graph memo, Haro v0.20): an agent proposes the BODY of a function whose signature a human
~~~ declared. Hand-composed BEFORE the engine reads them (the W discipline: fixtures first, code second); refine_check.py reads this file once the
~~~ engine is built, and until then stage 24 does not, so the guard stays green on the commits that carry them. Same sections as fixtures.txt;
~~~ `=== BNN` is a block fixture, `=== LNN` a fault in the lift.
~~~
~~~ THE POINT. `<R:BLOCK name="..." ...>` alone on the line above a `func`: the point is the function's BODY. Not on the func line: the grammar
~~~ reads a comment there as the body's first line, which the agent writes -- the tag would sit inside its own point. The signature -- the
~~~ function's name and parameters -- is the human's, and no block refinement changes it.
~~~   calls="A|B"     every function and builtin the body may call, spelt as declared (D24); absent, the body may call nothing. A method call
~~~                   `x.M()` counts as a call of M. Least authority: what is not named is refused.
~~~   writes="$x|.."  every global, and every parameter whose CONTENTS it writes (`aL[1] = 0`, `add(aL, v)`: the caller holds those), the body may
~~~                   write; absent, it writes its own locals only. Assigning a parameter itself is a local write (C-29).
~~~   risk, floor, governed_by   as for every point.
~~~
~~~ THE VALUE. A block's value is its body's CANONICAL text (the printer's: each statement at the body's own level, a line each, every line
~~~ ending in a newline). FROM is its digest -- `sha:` and the first 12 hex digits of its SHA-256; the empty body is `sha:e3b0c44298fc` --
~~~ because a body can hold what a one-line string cannot (a comment, a line break), and FROM is a compare-and-swap of what the proposer saw. The
~~~ lift prints it, so an agent copies it. TO is the new body on ONE line, as Ring reads statements without separators: the sentence has no line
~~~ break and no escape (F-55). The compiler's parser reads it and the printer writes it out canonically; the refined program read back must be the
~~~ same graph, or the proposal is refused. A respacing is not a refinement (D25): the value is the canonical text, and it does not move.
~~~
~~~ THE GATE, for a block:
~~~   structural   the body is a statement list and nothing else: it defines nothing (`func`, `class`), loads nothing, packages nothing; no
~~~                `eval`, no `call` by name, no brace block -- the gate could not say what they call; no comment -- the gate does not judge prose,
~~~                and a model's comment can mislead the human reading the diff; FROM is the body's digest now; TO parses
~~~   constraint   every call is one the point names in `calls`, by its declared spelling; every write outside the frame is one `writes` names
~~~   governance, trust   as for every point
~~~   derivation   the compiler is asked: `rnxc check` reports no error or warning on the refined program that it did not report before --
~~~                a call with the wrong number of arguments, a name nothing assigns -- and the refusal quotes the compiler. A program the compiler cannot vouch for
~~~                (its absence rules are shut: an eval, a loadlib) is not refined by a body at all.
~~~
~~~ THE LOWERING. The old body and the new are matched statement by statement on their canonical text (a longest common subsequence): a statement
~~~ that stays keeps its id and its comments, one that goes is `node.delete`, one that comes is `node.create` with a fresh id, deletes first. A
~~~ comment attached to a statement (rung 18's rule, the memo's 3.3) goes and stays with it. The inverse restores every id.

=== B01 a block point in the lift: the body's digest, and what it may call
--- program
$nVat = 0.20  # <R:PARAM name="vat" min="0" max="0.9">
? Gross(100)

# <R:BLOCK name="gross" calls="Tax">
func Gross(nNet)
	return nNet + Tax(nNet)

func Tax(n)
	return n * $nVat
--- lift
vat param @1 = 0.20 min=0 max=0.9
gross block @4 = sha:e50ec955b97f calls=Tax
